# Пара за 5.10.2026

На паре мы прошли:

- Зачем нужен DNS — чтобы браузер мог находить IP-адрес сайта по его имени (как телефонная книга), раньше всё вносили вручную, теперь автоматически.
- Как работает запрос: браузер → файл hosts → локальный DNS-сервер → региональные/корневые серверы → возврат IP.
- DNS-серверы: зачем нужны, что бывают у провайдеров, компаний и персональные, как работают в связке и кэшируют записи.
- Типы записей: A, MX, CNAME, NS, TXT, SPF, SOA и что такое DNS-зоны.
- Подробно SOA-запись: её поля (Primary Name Server, Hostmaster, Serial, Refresh, Retry, Expire, Minimum TTL).
- Корневые серверы: 13 основных, разнесённых по миру (и их копии).
- DNS как протокол: прикладной уровень OSI, есть в каждой ОС, DNSSEC для защиты от подмены.
- Уровни доменов: нулевой (корень), первый (зоны: национальные .ru и общие .com), второй (основной домен) и третий (поддомены/субдомены).
