# Пара за 29.09.2026

На паре мы прошли:

- Зачем нужен NAT: адресов IPv4 не хватает, поэтому частные адреса (10.x, 172.16.x, 192.168.x) переводятся в публичные, чтобы выходить в интернет.
- Терминология: разобрали 4 типа адресов (Inside/Outside Local/Global) — кто, от чьего лица и где виден.
- Типы NAT: Static — один к одному (для серверов, к которым нужен доступ снаружи). Dynamic — многие ко многим (из пула адресов). PAT (NAT Overload) — много к одному, с использованием портов (так работает домашний роутер).
- Настройка на Cisco: разобрали команды (ip nat inside/outside, пулы, ACL, overload) и проверку (show ip nat translations).
- Плюсы и минусы: экономия адресов и скрытие внутренней сети, но теряется сквозная адресация, сложнее с VoIP, IPsec и трассировкой.
