## Транспортный уровень

Транспортный уровень обеспечивает обмен данными между приложениями на разных устройствах и использует для их различения номера портов. Его основные задачи — сегментация данных, передача между узлами, управление потоком и, при необходимости, обеспечение надёжности.

Главные протоколы этого уровня — TCP и UDP.

**UDP** передаёт отдельные дейтаграммы без установления соединения и не гарантирует доставку или порядок сообщений, зато работает быстро и имеет небольшие накладные расходы. UDP часто используется для DNS, DHCP, TFTP и SNMP, а также для коротких запросов и ответов.

**TCP** обеспечивает надёжную передачу потока байтов, подтверждает получение данных, повторно отправляет неподтверждённые сегменты и восстанавливает правильный порядок данных. TCP устанавливает соединение с помощью трёхэтапного рукопожатия SYN, SYN+ACK и ACK, а завершает его с помощью управляющих флагов. Для эффективной передачи TCP использует скользящее окно и управление потоком, чтобы не перегружать получателя. TCP также регулирует передачу с учётом перегрузки сети.

**Сокет** — это совокупность IP-адресов и портов клиента и сервера, которая идентифицирует TCP-соединение. Порт определяет приложение на устройстве, а сокеты используются приложениями для взаимодействия через транспортный уровень.

Выбор между TCP и UDP зависит от того, что важнее для приложения: надёжность передачи или скорость.
