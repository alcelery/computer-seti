# Theory

Папка с теоретическими материалами по предмету.

Здесь хранятся презентации, конспекты, схемы и прочие материалы для изучения теории — всё, что дополняет лекции и помогает готовиться.

## Структура

    theory/
    ├── README.md
    ├── DHCP короткий.pptx
    ├── DNS.pptx
    ├── Ipv4.pptx
    ├── nat в cisco.pptx
    ├── nat теор.pptx
    ├── tcp.udp1.pptx
    ├── tcp.udp.2.pptx
    ├── tcp.udp.3.ppt
    ├── Коммутация Ethernet.pptx
    ├── маршрут циско.ppt
    ├── маршрут.ppt
    └── Модели.pptx

Каждая тема — отдельная папка по шаблону: topicNN_краткая_тема
Пример: topic03_алгоритмы_сортировки
